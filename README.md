## 修改导航数据

编辑 `docs/data.ts`，在对应分类的 `items` 数组中添加：

```ts
{
  icon: 'https://avatars.githubusercontent.com/owner',
  title: '项目名',
  desc: '简要描述',
  link: 'https://github.com/owner/repo',
}
```
